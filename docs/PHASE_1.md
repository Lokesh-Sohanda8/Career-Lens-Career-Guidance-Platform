# Phase 1 — Foundation

## Objective

Create a clean, runnable, testable backend foundation before implementing business domains.

## Deliverables

- repository structure
- environment configuration
- FastAPI application
- PostgreSQL connectivity
- SQLAlchemy setup
- Alembic
- base model
- error handling
- logging
- health/readiness
- testing foundation

## Deliberately deferred

- identity
- student profile
- assessments
- career intelligence
- recommendations
- skills
- education
- learning
- counselling
- reports
- AI/RAG

## Exit criteria

The repository is ready for Phase 2 when a developer can clone it, configure environment variables, start PostgreSQL/API, run migrations, execute tests, inspect API docs, and verify health/readiness.
